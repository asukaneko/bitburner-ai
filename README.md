# Bitburner AI 助手

适用于 Windows Steam 版 Bitburner 3.0.1 的中文 AI 助手。支持自定义 Chat Completions 兼容接口，可讲解玩法、编写脚本，并按玩家目标部署和运行游戏脚本。

## 功能

- 每轮模型循环上限可设置为 1–1,000 次，默认 200 次；循环次数保存在当前会话。
- 显示上下文占用比例：接口返回 Token 用量时显示实际值，否则按文本长度估算。可在模型设置中配置上下文窗口。
- 可以在游戏内手动压缩较早的会话上下文为本地摘要；对话显示保留原文，后续模型请求使用压缩后的摘要和近期内容。
- 讲解与写脚本、自动部署与运行两种模式。
- 读取角色、可达网络、服务器、游戏内文件、运行脚本和日志；查询当前游戏 API。
- 生成的脚本保存在 home 的 `ai/` 目录，覆盖前自动备份，运行时遵守游戏的 RAM 与权限检查。
- 自动整理长任务上下文，支持中途停止。
- 可手动压缩较早的会话上下文为本地摘要，保留原对话显示，并让后续请求携带更少的历史内容。
- 支持模型每轮循环上限和上下文窗口容量配置；循环次数保存在当前会话，上下文窗口保存在模型设置。
- Markdown 标题、列表、引用、表格、行内代码、代码块和代码复制。
- 全屏显示、键盘快捷键，以及与游戏终端隔离的输入处理。
- 会话新建、切换、重命名、删除与撤销；聊天、上下文和草稿在重启后恢复。
- API Key 通过 Electron `safeStorage` 加密保存；系统加密不可用时仅保留在进程内存。

## 安装

当前安装包适配 **Steam 3.0.1，并已安装 [s567901 的简体中文补丁](https://github.com/s567901/bitburner-zh-CN)** 的文件版本。安装器会校验原文件和游戏 bundle，文件不匹配时停止安装。

1. 完全退出游戏。
2. 将本仓库 `package/` 文件夹里面的全部内容复制到 `bitburner.exe` 所在目录。
3. 双击 `安装AI助手.bat`，完成后重新启动游戏。
4. 打开右下角“AI 助手”→“模型设置”，填写接口地址、模型名和 API Key，保存并测试连接。

接口地址可填写到 `/v1`，也可以填写完整的 `/chat/completions`。远程接口使用 HTTPS；本机服务可以使用 `http://127.0.0.1:端口/v1` 并留空 Key。自动模式需要模型支持 `tools/tool_calls`。

`Ctrl+Shift+A` 展开或收起助手，`Ctrl+Enter` 发送消息。全屏时按 Esc 先退出全屏，再按一次收起面板。

## 使用示例

> 看看我的进度，解释下一步应该做什么。

> 为我写一个循环 hack/grow/weaken 的脚本，先检查当前版本 API。

切换到“自动部署与运行”后：

> 分析可用目标，在不超出 home 内存的前提下部署一个赚钱脚本，并告诉我 PID。

“停止本轮”中止当前请求和后续操作；已运行的脚本会继续运行。“停止 AI 脚本”可以停止当前游戏会话中由助手启动的脚本。教程期间可以使用讲解功能，自动运行脚本需先完成或自行退出教程。

## 会话与卸载

会话保存在 Electron 用户数据目录的 `bitburner-ai.sessions/`，模型配置单独保存在 `bitburner-ai.settings.json`。重启会恢复上次会话；未结束的任务会标记为中断，不会自行继续执行。

双击游戏目录中的 `卸载AI助手.bat`，再重启游戏即可恢复安装前的汉化文件。原文件备份位于 `Bitburner-AI-Patch/backup/`。Steam 更新后可能需要重新适配。

详细操作见 [使用说明](package/使用说明.txt)。

## 开发与验证

需要 Node.js 22.12.0 或更高版本。

```sh
npm ci --ignore-scripts
npm run build
npm test
```

构建会将 `src/` 和锁定的 Markdown 依赖同步到安装包，并更新文件校验值。测试不依赖本机安装游戏；游戏相关校验使用仓库内的 3.0.1 测试夹具。

```text
src/                 助手界面、任务循环、游戏工具、模型接口与会话存储
scripts/             安装包构建脚本
tests/               回归测试和游戏代码夹具
package/             可直接复制到游戏目录的安装包
```

本地回归覆盖终端输入冲突、Markdown、全屏、会话重启恢复、200 次循环、工具调用、请求取消和文件校验。真实模型连接与游戏窗口中的运行效果需要使用者配置后验证。
