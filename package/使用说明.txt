Bitburner 3.0.1 中文 AI 助手 v1.1.0

安装后完全退出并重新启动游戏，右下角会出现“AI 助手”。Ctrl+Shift+A 也可以展开或收起面板。

首次使用
1. 展开“模型设置”。
2. 输入自定义兼容接口地址（例如 https://你的服务地址/v1）、模型名称和 API Key。
3. 点击“保存配置”和“测试连接”，成功后开始对话。API Key 不用发给聊天中的任何人。

会话与显示
顶部支持新建、切换、重命名、删除会话，删除后可以撤销。聊天、工具记录、上下文和输入草稿保存在本机用户数据目录的 bitburner-ai.sessions，重启后恢复上次会话。
退出时未结束的任务会标记为中断，重启后不会自行恢复执行。
“全屏”可放大对话；Esc 先退出全屏，再次按下收起面板。
AI 回复支持 Markdown 标题、列表、粗体、引用、表格、行内代码与代码块，代码块可以一键复制。

两种模式
讲解与写脚本：读取游戏状态、查询当前游戏 API、解释玩法、生成代码。
自动部署与运行：根据你的目标扫描网络、保存脚本并在 home 运行。脚本使用正常的 RAM 和权限检查。自动模式要求模型支持 Chat Completions 的 tools/tool_calls。

示例
“看看我的进度，解释下一步应该做什么。”
“为我写一个循环 hack/grow/weaken 的脚本，先检查当前版本 API。”
切到自动模式后：“分析可用目标，在不超出 home 内存的前提下部署一个赚钱脚本，并告诉我 PID。”

每轮任务最多进行 200 次模型循环，长任务会自动整理上下文。

脚本与停止
AI 生成的脚本保存到游戏内 home 的 ai/ 目录；覆盖前会备份到 ai/backups/。部署的脚本会随游戏正常保存。
“停止本轮”中止本轮模型请求和后续工具调用；已经运行的脚本会继续运行。
“停止 AI 脚本”停止当前游戏会话中由助手启动的脚本。重启后可在游戏的活动脚本页面自行停止此前运行的脚本。
教程期间可以使用讲解功能；自动运行脚本需要先完成教程或由你在游戏中退出教程。

接口配置
支持 Chat Completions 兼容接口，地址可填写到 /v1 或完整的 /chat/completions。
远程服务使用 HTTPS。本机服务可使用 http://127.0.0.1:端口/v1，且允许空 API Key。
Windows 系统加密可用时，密钥由 Electron safeStorage 加密后保存在用户数据目录的 bitburner-ai.settings.json；若系统加密不可用，密钥仅保留在当前进程内存。密钥不放进游戏存档或补丁压缩包。
对话与工具读取的游戏信息会发送给你配置的模型服务。聊天记录与草稿保存在本机；API Key 单独加密保存，不写入会话文件。

安装与卸载
将压缩包全部解压到 bitburner.exe 所在目录，双击“安装AI助手.bat”。安装期间游戏若仍运行，需完全退出并重启后才能使用。
卸载时双击“卸载AI助手.bat”，再重启游戏。卸载会恢复安装前的汉化文件。
原文件备份位于 Bitburner-AI-Patch/backup。此包适配本机已经汉化的 Steam 3.0.1，安装器会核对原文件和游戏 bundle 的校验值。
若要恢复英文，请先卸载 AI 助手，再运行原来的“还原英文.bat”。
Steam 更新可能覆盖插件，不同版本需重新适配。

验证范围
通过本地模拟接口的 HTTP 请求、工具调用流程、真实游戏编译代码中的 RAM 校验、取消操作、配置密钥隔离和 DOM 界面检查。
安装器测试包含安装、版本升级、重复安装、还原与文件校验。另有终端键盘冲突、Markdown、全屏、会话恢复及 200 次循环回归测试。
尚未接入你的实际模型服务，也未操作游戏窗口进行视觉验收或实际部署游戏脚本。
